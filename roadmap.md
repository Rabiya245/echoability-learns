# EchoAbility roadmap

- [x] Design system: adaptive sensory themes (dyslexia cream/high-contrast, autism calm pastel, dark) + reduce motion
- [x] Local device storage: profile, learning mode, progress, coins, streak, achievements, sensory prefs, special interest
- [x] Speech (text-to-speech) hook on interactive elements
- [x] Shell: mobile frame, bottom tabs (Home / Activities / Videos / Profile), Calm Corner floating button
- [x] Onboarding: name, avatar emoji, age, learning mode, special interest
- [x] Home: mode badge, daily affirmation sticker, module cards (mode-aware)
- [x] Calm Corner: breathing ring, soundscapes (rain/ocean/woods/campfire/white noise), quick calming tools
- [x] Social Skills module + scenario quizzes
- [x] Emotions & Regulation: zones, faces, coping choice board, feelings check-in
- [x] Visual Schedules: Now-Next-Then board + premade routines
- [x] Life Skills: step sequences + safety basics
- [x] English: Level 1 A-M, Level 2 N-Z, Level 3 sentences (learn + trace + quiz)
- [x] Maths: 0-50, 51-100, counting, operations
- [x] Special activities: colors, shapes, emotions, animals, fruits, memory, days, months
- [x] Videos with categories
- [x] Achievements + Profile stats, mode toggle, sensory prefs, parent/teacher tips
